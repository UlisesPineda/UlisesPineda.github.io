Sistema de Facturación Electrónica

Plataforma de facturación electrónica enterprise diseñada específicamente para cliente privado con necesidades específicas en su modelo de facturación, con cumplimiento nativo del estándar CFDI 4.0 y Complemento de Pagos 2.0 del SAT.

Arquitectura:
  • Patrón: Modular Monolith (documentado por Martin Fowler) — dominios de negocio encapsulados, desplegables como una unidad, pero con capacidad futura de extracción a microservicios

  • DD (Domain-Driven Design): Cada módulo representa un Bounded Context (facturación, clientes, productos, timbrado, autenticación).

  • CQRS: Separación de comandos (escritura) y consultas (lectura) dentro de cada módulo.

  • Hexagonal Architecture / Adapter Pattern: El sistema interno no conoce detalles de infraestructura externa (ej. servidor PHP de timbrado encapsulado como StampingProvider).

  • Event-Driven Architecture interna: Comunicación entre módulos mediante eventos tipados, no importaciones directas.

  • Queue-based Load Leveling: Procesamiento asíncrono con colas (BullMQ) para evitar reprocesos y duplicados.
Seguridad y Control:
  • Access Token (15 min) + Refresh Token (7 días en Redis), con revocación instantánea.

  • Roles diferenciados (admin, contador, visualizador) con decoradores en cada endpoint.

  • Rate limiting por IP y por usuario.

  • Validación estricta de inputs con class-validator en la capa de transporte.

  • Variables de entorno y Docker Secrets, nunca en código.

  • TLS en todas las comunicaciones.
Observabilidad y Auditoría:
  • Audit trail completo, se registra quién, cuándo, qué, con qué datos y resultado.

  • Tablas de auditoría

  • Dashboard de monitoreo de colas (Bull Board).
Estructura Modular:
  • Capa de Presentación (Next.js)

  • Capa de Transporte (NestJS Guards, Interceptors, Pipes)

  • Capa de Aplicación (Casos de uso, Commands, Queries)

  • Capa de Dominio (Entidades, value objects, reglas de negocio)

  • Capa de Infraestructura (Repositorios, ORM, servicios externos, colas)

  • Capa de Datos (PostgreSQL + Redis)
